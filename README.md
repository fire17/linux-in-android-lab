# linux-in-android-lab

Three Android experiments by Tami Bar (fire17):

| App | What |
|---|---|
| `linux-in-app/` | LinuxInApp: real Alpine Linux userland inside an app (PRoot) |
| `linux-desktop-chrome/` | LinuxDesk: the app screen IS a Linux X11 display running Chromium |
| `android-in-android/` | PhoneInPhone: Android inside Android (stream backend + on-device ladder experiment) |

Each folder has its own README with an honest verification status. APKs are built by GitHub Actions (see the Actions tab, artifacts).
